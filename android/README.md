# Любимка для Android

Проект открывается в Android Studio. Идентификатор приложения `online.lubimka.app`, версия `1.0.0`, код сборки `1`. Минимальная версия Android 8.0 (API 26), целевая и компилируемая версии API 36.

Клиент использует рабочий сайт по HTTPS и отдельное хранилище сессии Android WebView. Для первого входа потребуется email-код или подтверждение в обычном Telegram. После подтверждения вернитесь в «Любимку» через переключатель приложений. Уже зарегистрированный пользователь входит тем же способом, что на сайте. Внешние сайты и зоотакси открываются через операционную систему.

Кнопка «Поделиться» в публичном объявлении вызывает системное меню. Приложение также принимает публичную ссылку из системного меню «Поделиться» другого приложения. Удерживание иконки → «По ссылке» позволяет вставить адрес вручную. Входящие ссылки проверяются по домену и идентификатору объявления. Личные разделы и параметры ссылок исключены из обмена.

Выбор изображений работает через системную панель Android. Кнопка определения местоположения на сайте может запросить только примерную геопозицию во время использования. SDK аналитики и рекламы в Android-клиенте отсутствуют.

## Сборка

На 64-битной Windows можно дважды нажать **СОБРАТЬ-ANDROID.cmd**. Скрипт использует установленный SDK или предложит скачать официальные инструменты. Первая загрузка потребует интернет. Просмотрите условия по ссылке и введите `YES` только если согласны. Если стандартный установщик Google отдельно покажет текст лицензии, ответьте в его окне. Получатся тестовый APK и неподписанный AAB. Подпишите выпускной файл своим upload key по шагу 4. При работе через Android Studio:

1. Установите Android Studio, Android SDK Platform 36 и Android SDK Build-Tools 35.0.0 через SDK Manager. Просмотрите условия Google и подтвердите их лично, если согласны. Укажите SDK в Android Studio или переменной `ANDROID_HOME`.
2. Откройте эту папку как проект. Для Gradle используйте JDK 17 или совместимый встроенный JDK Android Studio. Версии Gradle и Android Gradle Plugin зафиксированы в проекте.
3. Из этой папки в PowerShell запустите `.\gradlew.bat :app:assembleDebug :app:bundleRelease`. На macOS/Linux используйте `sh ./gradlew :app:assembleDebug :app:bundleRelease`. Файлы появятся в `app/build/outputs/apk/debug/app-debug.apk` и `app/build/outputs/bundle/release/app-release.aab`. По умолчанию release AAB не подписан, debug APK предназначен для тестов.
4. В Android Studio выберите **Build → Generate Signed App Bundle or APK → Android App Bundle → release**. Владелец создаёт или выбирает upload key и хранит его вместе с паролем в собственном защищённом месте. Подписанный AAB нужен для Play Console. Для следующих сборок увеличивайте `versionCode`.

## Проверка на устройстве

- Откройте приложение, войдите через Telegram и вернитесь из Telegram. Обновите экран и проверьте своих питомцев. Повторите для email-входа на тестовой учётной записи.
- Откройте системный выбор фото, отмените, затем выберите изображение. В форме проверьте сохранение на отдельном тестовом контуре.
- Откройте карту, отклоните запрос геолокации и выберите город вручную. Повторите с разрешением приблизительного местоположения. Проверьте поле ввода при открытой клавиатуре.
- Поделитесь публичным объявлением через системное меню. Отправьте ссылку обратно в «Любимку» и воспользуйтесь ярлыком «По ссылке». Для обычного браузерного URL Android сохранит стандартную обработку ссылок.
- Используйте жест «Назад» в диалоге и на вложенной странице. Проверьте запуск в авиарежиме, восстановление сети и кнопку «Попробовать снова».
- Из карточки питомца сохраните QR и PDF, из объявления — PNG-плакат. Выберите папку через системное окно Android и откройте файл. Повторите с отменой. Лимит одного файла в приложении — 12 МБ.

Для модульной проверки ссылок достаточно JDK 17. Из этой папки запустите `javac -encoding UTF-8 -d build/link-tests app/src/main/java/online/lubimka/app/Links.java tests/LinksTest.java` (сначала создайте папку `build/link-tests`), затем `java -cp build/link-tests online.lubimka.app.LinksTest`.
